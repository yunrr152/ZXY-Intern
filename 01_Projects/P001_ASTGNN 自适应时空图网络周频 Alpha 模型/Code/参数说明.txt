ASTGNN 参数说明
=============

本文件说明 config.py 中当前 ModelConfig 的参数含义和默认值。
day 数据训练入口会显式设置 use_resnet=False，因此实际路径为：
预处理 -> GRU -> TGC -> 弱因子 Z -> LightGBM -> 最终预测 C。

输入与网络结构
--------------
seq_len = 30
  每只股票的历史输入长度，单位为交易日。

num_features = 6
  每日输入特征数。day 数据按 high、open、low、close、vwap、volume 排列。

num_days = 5
  仅供 ResNet 的四维输入 [N, 时间片, 交易日, 特征] 使用；day 数据不使用。

feature_dim = 6
  ResNet 输出给 GRU 的特征维度；day 数据不使用。

use_resnet = True
  是否启用 ResNet。config.py 的默认值为 True，但 training/train.py 的 day 训练入口
  会覆盖为 False。

resnet_kernel_size = 3
  ResNet 一维卷积的卷积核大小。

resnet_padding = 1
  ResNet 一维卷积的填充大小。应与卷积核匹配，以保证残差连接前后的长度一致。

gru_hidden_dim = 64
  每条 GRU 分支最后隐藏状态的维度，也是 G 的维度。

gru_seeds = (0, 47, 427)
  三条独立 GRU 分支的初始化种子。元组长度决定 GRU 分支数量。
  此项不同于 random_seed；它专门控制各条 GRU 的独立初始化。

graph_embed_dim = 16
  股票节点嵌入矩阵 M 的维度，用于构造自适应邻接矩阵。

tgc_hidden_dim = 64
  TGC 输出 T 的维度。

tgc_embedding_init_std = 0.01
  节点嵌入矩阵 M 的正态初始化标准差。

num_factors = 64
  弱因子矩阵 Z 的列数，也是 LightGBM 的输入特征数。

BatchNorm 参数
--------------
batch_norm_eps = 1e-5
  BatchNorm 分母中的数值稳定项。

batch_norm_momentum = 0.1
  训练时更新运行均值和运行方差的动量。

batch_norm_affine = True
  是否学习 BatchNorm 的缩放和偏移参数。

batch_norm_track_running_stats = True
  是否保存训练期的运行统计量，并在 eval() 验证期使用。

数据预处理与标签
----------------
winsorize_mad_multiplier = 7.0
  去极值阈值：中位数 +/- 7 倍中位数绝对离差（MAD）。

target_start_offset = 1
  标签起点为 T+1 的收盘价。

target_end_offset = 11
  标签终点为 T+11 的收盘价。
  收益率标签为 close[T+11] / close[T+1] - 1。

training_years = 10
  每次滚动训练所使用的历史自然年数量。

min_stocks_per_cross_section = 2
  训练截面的最低股票数。低于该值时跳过，以避免训练态 BatchNorm 无法计算。

ASTGNN 第一阶段训练
--------------------
random_seed = 42
  模型初始化和 LightGBM 的随机种子。

device = "cpu"
  运行设备。若 astgnn 环境可用 CUDA，可改为 "cuda"。

learning_rate = 1e-3
  AdamW 的学习率。

weight_decay = 1e-5
  AdamW 的权重衰减系数。

adam_beta1 = 0.9
  AdamW 一阶矩估计的衰减系数。

adam_beta2 = 0.999
  AdamW 二阶矩估计的衰减系数。

adam_eps = 1e-8
  AdamW 的数值稳定项。

adam_amsgrad = False
  是否启用 AdamW 的 AMSGrad 变体。

epochs = 20
  每个年度滚动模型的训练轮数。

lambda_orth = 0.01
  弱因子正交正则损失 L_orth 的系数。

lambda_adv = 0.01
  对抗损失 L_adv 的系数。设为 0 时完全关闭对抗训练。

当前第一阶段总损失为：
  L = L_pred + lambda_orth * L_orth + lambda_adv * L_adv

图邻近损失尚未加入，符合当前不使用先验邻接矩阵的设定。

IFGSM 对抗训练
--------------
adv_epsilon = 0.01
  对抗样本相对预处理输入的最大扰动范围。

adv_step_size = 0.005
  每次 IFGSM 迭代的扰动步长。

adv_steps = 3
  IFGSM 迭代次数。

LightGBM 弱因子非线性加权
---------------------------
lgbols_lookback_years = 1
  使用验证年前多少个自然年的 Z 和收益率标签训练 GBDT。

lgbols_num_boost_round = 100
  GBDT 的 boosting 轮数，即树的数量。

lgbols_objective = "regression"
  LightGBM 的回归目标函数。

lgbols_boosting_type = "gbdt"
  LightGBM 的提升方式。

lgbols_learning_rate = 0.05
  每棵树的学习率。

lgbols_num_leaves = 31
  单棵树的最大叶节点数；数值越大，树模型的表达能力越强。

lgbols_num_threads = 1
  LightGBM 使用的 CPU 线程数。

lgbols_verbosity = -1
  LightGBM 日志等级；-1 表示静默。

因子合成说明
------------
modules/predictor.py 中的 Z.mean(dim=1) 是弱因子的等权内部评分，
仅用于第一阶段 ASTGNN 的可微训练、MSE 和 IFGSM。

最终验证期 C 由训练好的 LightGBM 执行 booster.predict(Z) 得到。
GBDT 通过树的分裂路径和叶节点输出对弱因子做非线性组合，
因此不存在固定的线性因子权重向量。

命令行临时覆盖
--------------
training/train.py 支持以下命令行参数临时覆盖配置：
  --epochs
  --device
  --seed
  --lgbols-lookback-years
  --lgbols-num-boost-round

未传入以上命令行参数时，使用 config.py 中的默认值。
