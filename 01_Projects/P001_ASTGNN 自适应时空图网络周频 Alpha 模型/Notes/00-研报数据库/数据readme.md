# 即用数据库 A · 股票研究数据使用说明

这四个目录可以离线使用。查“哪天开市”读交易日历，查“这是谁”读证券主表，查“这只股票当天发生了什么”读日线，查“这天可以从哪些股票中选样本”读股票池。同一个股票日用 **交易日整数和带交易所后缀的股票代码** 对齐，例如 `20261117` 和 `000001.XSHE`。

## 1 本次交付与快速读取

| 目录                     | 一条记录表示什么                | 本盘覆盖                                 | 格式  |
| ---------------------- | ----------------------- | ------------------------------------ | --- |
| `LX_GEN_TIME_TRADEDAY` | 沪深市场一个开市日               | 5829 日，20040102–20271231             |     |
| `LX_STK_INFO_AH`       | 当前快照中一条沪深 A 股或香港证券记录    | 4 张证券表，含上市和历史退市证券                    |     |
| `LX_STK_BASIC_DAILY`   | 一只沪深 A 股在一个交易日的行情、估值及状态 | 5566 个股票目录，38 个字段，20060104–20261117  |     |
| `LX_STK_POOL_BASIC`    | 一只股票在某交易日是否属于指定股票池      | 11 个池，每池 4828 个交易日，20070104–20261117 |     |

在能导入 `numpy`、`pandas`、`pyarrow` 的 Python 环境中，以下示例可直接读取四个库。先把工作目录切到包含这四个文件夹的位置。示例取平安银行最后一个行情日，并查当天是否属于新版增强全市场池。

```python
from pathlib import Path
import numpy as np
import pandas as pd

root = Path.cwd()
code = "000001.XSHE"
days = np.fromfile(root / "LX_GEN_TIME_TRADEDAY" / "tradeDay.dat", dtype="<i4")
master = pd.read_parquet(root / "LX_STK_INFO_AH" / "AShareLSDE.parquet",
                         columns=["code", "secShortName", "listDate"])
folder = root / "LX_STK_BASIC_DAILY" / code
dates = np.fromfile(folder / "di.dat", dtype="<i4")
bars = pd.DataFrame({
    "closeN": np.fromfile(folder / "closeN.dat", dtype="<f4"),
    "ret1d": np.fromfile(folder / "ret1d.dat", dtype="<f4"),
    "turnoverValue": np.fromfile(folder / "turnoverValue.dat", dtype="<f8"),
    "tradeStatus": np.fromfile(folder / "tradeStatus.dat", dtype="<f4"),
}, index=pd.Index(dates, name="date"))
pool = pd.read_parquet(root / "LX_STK_POOL_BASIC" / "advanceWholeMarketNew.parquet",
                       columns=[code])
day = int(dates[-1])
assert day in days and day in pool.index
print(master.loc[master["code"].eq(code)].to_string(index=False))
print(bars.loc[day])
print("当日在池", pool.at[day, code] == 1)
```

只读某只股票时，直接打开它的目录；只读票池里的少量股票时，给 `read_parquet` 传 `columns`。提取某天全部成员可读整张票池，取 `row = pool.loc[day]`，再取 `row.index[row.eq(1)]`。不同票池的列集合可能不同。

## 2 交易日历 · LX_GEN_TIME_TRADEDAY

唯一的数据文件 `tradeDay.dat` 是无表头的一维小端 `int32` 数组，每个元素占 4 字节，值为升序、去重的 `YYYYMMDD`。构建时调用通联 `TradeCalGet`，筛选上海、深圳交易所的开市日期，核对两市日期出现次数的一致性后整列覆盖。==日历预先延伸至下一自然年年末，所以查询“最后一个有行情的日期”应读取股票的 `di.dat`。==香港证券的交易日安排应另查香港日历。

## 3 证券主表 · LX_STK_INFO_AH

| 文件 | 本盘行数 | 选取范围 |
|---|---:|---|
| `AShareL.parquet` | 5224 | 沪深 A 股，当前上市，剔除已有明确摘牌日的记录 |
| `AShareLSDE.parquet` | 5567 | 沪深 A 股，查询上市、暂停上市及终止上市状态，适合查历史股票 |
| `HShareL.parquet` | 2795 | 香港市场主板及创业板，当前上市且无明确摘牌日 |
| `HShareLSDE.parquet` | 6091 | 同一香港市场范围，含历史退市记录 |

A 股取通联 `EquGet`，限定主板、创业板、科创板。香港取 `HKEquGet`，覆盖上述板块的香港证券，范围比内地企业发行的 H 股更广。每次抓取最新主表并覆盖；每行描述证券在该次快照中的状态。==研究历史样本时，用历史日期的股票池和日线状态筛选，直接套用今天的上市名单会漏掉后来退市的股票。==

| 字段                                                  | 含义及用法                                                                                                       |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `ticker`、`exchangeCD`、`code`                        | 本地交易代码、交易所、两者以点号拼成的研究代码。保留前导零。沪、深、港分别为 XSHG、XSHE、XHKG。用 A 股表的 `code` 匹配日线目录和股票池列名。                          |
| `secID`、`partyID`                                   | 通联证券标识、发行主体标识。换码或代码复用时应核对上市区间。例如 A 股表中 `code=001914.XSHE` 对应 `secID=000043.XSHE`；香港历史表中同一 `code` 可对应多条证券记录。 |
| `secShortName`、`secFullName`、`secShortNameEn`       | 快照时的证券简称、全称及英文简称。英文简称列仅在港股表内。                                                                               |
| `listDate`、`delistDate`、`listStatusCD`              | 上市日为 YYYY-MM-DD 字符串，摘牌日为 YYYYMMDD 整数，缺少明确摘牌日用 `99991231` 占位。状态 L 为上市、S 为暂停上市、DE 为终止上市。单日停牌见日线 `halt`。       |
| `ListSectorCD`、`ListSector`、`equTypeCD`、`equType`   | 上市板块及证券分类，各有编码和名称；列名区分大小写。                                                                                  |
| `transCurrCD`、`exCountryCD`                         | 交易币种、交易市场所在国家或地区代码。                                                                                         |
| `totalShares`、`nonrestFloatShares`、`nonrestfloatA`  | A 股表中的总股本、无限售流通股合计、无限售流通 A 股，单位为股。它们是快照值；逐日历史股本见日线。                                                         |
| `endDate`、`TShEquity`、`officeAddr`、`primeOperating` | A 股表的报告期末、股东权益合计、办公地址和主营业务。==报告期末与实际披露日期有别。==                                                               |
| `tradingUnit`、`connect`                             | 港股表的每手交易单位及港股通标记。0 为未纳入，1 为仅深港通，2 为两者均覆盖，3 为仅沪港通。                                                           |

全状态 A 股主表有一条历史非标准代码 `DY600018.XSHG`，构建日线时过滤了非数字股票代码，因此主表的 5567 行与日线的 5566 个目录可以同时成立。

## 4 股票日线 · LX_STK_BASIC_DAILY

每只股票一个目录，每个字段一个同名 `.dat` 文件。例如 `000001.XSHE/closeN.dat` 的第 i 项对应同目录 `di.dat` 的第 i 个交易日。文件没有表头、日期列或内嵌类型信息。**先读本股日期轴，再按字段类型读取数值**；不同股票用日期连接。全历史日期轴含上市前或摘牌后的占位行，做成交统计时用 `tradeStatus == 1`，价格与估值缺失保留 NaN。

### 4.1 字段字典

`di` 为小端 `int32`；`turnoverValue`、`marketValue`、`negMarketValue` 为小端 `float64`；其余 34 个字段均为小端 `float32`，包括状态标记。用相应类型读出后，同一股票每列元素个数应与 `di` 相同。

| 字段                                  | 含义、单位与口径                                                                                |
| ----------------------------------- | --------------------------------------------------------------------------------------- |
| `di`、`ii`                           | 交易日整数、股票代码的数值部分。例如平安银行的 `ii` 为 1，跨库连接使用目录名 `000001.XSHE`。                               |
| `openN`、`highN`、`lowN`、`closeN`     | 未复权开盘、最高、最低、收盘价，元/股；与当日实际报价、涨跌停价比较用这一组。                                                 |
| `openA`、`highA`、`lowA`、`closeA`     | 对应的后复权开、高、低、收，按后复权尺度计价。                                                                 |
| `preCloseN`、`preCloseA`             | 当日行情使用的昨收基准，分别为未复权、后复权。除权除息日及上市首日应使用当日基准。                                               |
| `accumAdjFactorA`、`accumAdjFactorB` | 累积后复权因子、前复权因子。前复权因子等于后复权因子除以本次数据末个有效因子；前复权价可用未复权价乘前复权因子。                                |
| `limitUpPriceN`、`limitDownPriceN`   | 未复权涨停价、跌停价，元/股。                                                                         |
| `volumeN`、`volumeA`                 | 实际成交量、后复权口径成交量，单位为股。计算股数换手使用 `volumeN`。                                                 |
| `turnoverValue`、`dealAmount`        | 成交金额（元）、成交笔数（笔）。                                                                        |
| `vwapN`、`vwapA`                     | 成交量加权均价，分别按未复权、后复权口径计价。                                                                 |
| `ret1d`                             | 当日涨跌幅，以百分数存储。值 2.5 表示上涨 2.5%，做连乘前先除以 100。                                               |
| `sharesAll`、`freeShares`            | 当日生效总股本、无限售流通 A 股股数，单位为股。`freeShares` 采用无限售口径。                                          |
| `marketValue`、`negMarketValue`      | 总市值、无限售流通市值，单位为元；分别用当日未复权收盘价乘上述两种股数。股本列以单精度保存，直接用落盘股数回乘可能有微小舍入差。                        |
| `turn`、`freeTurn`                   | 股数换手与金额换手，均为基点（100 基点 = 1%）。前者为实际成交量除以无限售流通股数，再乘 10000 取整；后者为成交额除以无限售流通市值，再乘 10000。     |
| `PE_TTM`、`PE`、`PB`                  | 单位为倍。分子均为总市值，分母依次为滚动十二个月归母净利润、最新一期累计归母净利润年化值、归母股东权益。分母为零或缺失时保留 NaN。                     |
| `tradeStatus`、`halt`、`st`           | 当日行情开市标记（1 表示有交易，0 表示未开市）、交易时段内是否发生停牌、当日是否处于 ST。盘中临停可同时出现 `tradeStatus=1` 和 `halt=1`。   |
| `MaxAndDown`、`oneTypeMaxAndDown`    | 前者表示收盘封在涨停或跌停附近，上下限均有效时判定，相对容差为 0.0001；后者还要求当日最高价减最低价不超过 0.001 元。两个标志均以 1 表示命中，不区分涨跌方向。 |
| `valid`                             | 上市年限标志。对有行情记录的位置，当日期整数严格大于上市日期整数加 10000 时取 1，其余按 0 初始化。ST、停牌和入池资格分别看对应字段。               |

### 4.2 构建顺序与历史口径

1. 使用沪深交易日历和 A 股全状态主表建立日期、股票范围。分别从 `MktEqudGet`、`MktEqudAdjAfGet` 取未复权和后复权行情，按实际交易日对齐；再合并 `MktLimitGet` 的价格限制、`SecSTGet` 的 ST 记录和 `SecHaltGet` 的停牌时段。可由上市区间或全天停牌解释的缺行情日保留占位。
2. 首次发行上市日以发行价作为昨收基准，并据此计算首日收益；已核实未重新发行的重上市或转板事件使用行情参考价。每次更新对整段前复权因子重新归一，新增除权事件可能改变旧日期的前复权水平。`000043.XSHE` 与 `001914.XSHE` 共用连续复权基准，再按换码生效日 `20191216` 拆分。
3. 股本按生效日选取，市值与换手由原始价量和有效股本计算。估值从原始利润表、资产负债表按实际披露时间选版。对行情日 D，使用严格早于**下一交易日北京时间 00:00**公开的财报。因此 D 收盘后至截止时刻的公告可能已进入 D 行估值；用这行做信号时，应把决策时点放在信息已可得之后。
4. 空库从历史首日逐股构建，后续按缺口追加；更新器校验日期连续性和列长度。这批数据于 20261118 从空库重建，覆盖至 20261117。历史估值在少量早期成交日仍有缺失，统计估值覆盖率时应保留缺失与真实零值的区别。

## 5 股票池 · LX_STK_POOL_BASIC

每个文件是一张宽表，行索引为交易日整数，列名为股票代码。**值等于 1 表示当天在池**；0、空值或该股票没有出现在列集合中，均不计入成员。成员是随日期变化的集合，列数是整段历史出现的股票范围。用当日收盘数据构建的池适合在收盘后选样；模拟开盘决策时应使用此前已知的成员。

### 5.1 全市场和增强池

| 文件（均以 `.parquet` 结尾）          | 成员规则                                                                                                             |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `wholeMarket`                 | 股票上市满 6 个日历月且早于摘牌日。剔除当日 ST、停牌和一字涨跌停。这里的上市等待期与日线 `valid` 的一年条件不同。                                                 |
| `advanceWholeMarket`          | 在 `wholeMarket` 成员内，分别按总市值和成交额的近 60 个交易日均值排名（各至少 30 个有效值），两项百分位均须 ≥ 10%。另要求近 20 个交易日的最高未复权收盘价 ≥ 2 元（至少 12 个有效值）。 |
| `wholeMarketNew`              | 沿用 `wholeMarket`，另剔除退市整理期。由最新简称圈出候选，再查历史逐日简称，当天简称含“退”的日期才按整理期剔除。                                                 |
| `advanceWholeMarketStrictNew` | 在 `wholeMarketNew` 上剔除两类股票：最近 20 个实际成交日收盘价全部低于 2 元；或近 60 个实际成交日日均总市值和日均成交额在当天基础池中的百分位**同时 ≤ 10%**。               |
| `advanceWholeMarketNew`       | 与上项同法，规模和流动性的双低阈值改为 **同时 ≤ 5%**，低价门槛相同。                                                                          |

两个新版增强池按每只股票自己的成交日滚动，停牌日沿用最近窗口；成交日不满 20 或 60 时，对应条件暂不触发剔除。旧版按市场交易日滚动，观测数不足时无法通过筛选。复现时应先选定票池名，再取该日成员。

### 5.2 指数成分派生池

下表的指数均使用**对应日期**的成分股。中证500、800、1000、全指在构建时分别取 `000905`、`000906`、`000852`、`000985` 的成分表。

| 文件（均以 `.parquet` 结尾） | 当日集合运算 |
|---|---|
| `smallValue` | 中证全指剔除中证800和中证1000，再与 `advanceWholeMarket` 取交集。 |
| `zz1500` | 中证500与中证1000的并集。 |
| `zz1800` | 中证800与中证1000的并集。 |
| `mediumSmallValue` | `smallValue` 与中证1000的并集。 |
| `proMediumSmallValue` | `mediumSmallValue` 与中证800的并集。 |
| `exclude800` | 从 `wholeMarket` 中剔除中证800。 |

票池在日线更新后按全历史重算并覆盖。直接使用盘中的 11 张成品表即可做历史选样。若要从头复建，除这四个库外，还需通联历史行情、股本与财报、逐日简称和历史指数成分等上游数据。
